Limits

What ghaplan can and cannot evaluate

✓

What ghaplan can evaluate

Push, pull request, dispatch, schedule, merge group, and workflow run events. It also checks branch and path rules, job conditions, matrices, and dependencies.

—

What ghaplan leaves unknown

Secret values, runner files, remote workflows, and live GitHub state are marked unknown.

Plain privacy

Privacy for the workflow planner

ghaplan runs in your browser. Planning sends no workflow text, analytics, or uploads.

What the site stores

Demo edits use keys beginning with demo: in this browser. Reset demo removes them. Real planning does not use browser storage.

Accounts

The site has no accounts.
