# Changelog

All notable changes follow [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-08-27

- Add the `ghaplan` Rust library and single-binary CLI.
- Evaluate event filters, core expressions, matrices, step decisions, and
  dependency order with explicit unknown states.
- Report referenced secrets and permissions without reading secret values.
- Add stable JSON output and strict CI exit behavior.
- Add the offline-capable static browser planner and product documentation.
